# Security policy

Do not open public issues for suspected vulnerabilities. Report them privately to the security contact configured for the project deployment, including reproduction steps and impact. Maintainers should acknowledge a report within three business days, preserve reporter confidentiality, issue a CVE when appropriate, and publish a coordinated fix and advisory.

Supported releases are the latest minor release and any explicitly listed long-term-support release. Never include live credentials, approval contents, evidence, signing keys, or personal data in a report.

The system trust boundary and residual risks are documented in [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md).
